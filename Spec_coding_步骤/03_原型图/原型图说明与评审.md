## 2. 格式依据（从老师原型逆向得出，非猜测）

| 项 | 结论 |
|---|---|
| 容器 | 纯 JSON，根为 `{"version", "children"}`；版本用 `2.11`（老师 11 个文件中 9 个用此版本） |
| 组件 | **只有 5 种**：`frame` / `text` / `rectangle` / `ellipse` / `icon_font` |
| **布局语义** | **缺省 `layout` = 横向排列（row）**；`"vertical"` = 纵向；`"none"` = 绝对定位（靠 `x`/`y`）。**与 CSS 直觉相反，搞错会导致全部元素堆叠** |
| 尺寸 | 整数，或字符串 `"fill_container"`（撑满父容器） |
| 字体 | 正文 `Inter`，品牌与数字 `Funnel Sans`，代码 `IBM Plex Mono` |
| 字重 | 字符串：`normal` / `500` / `600` / `700` |
| 图标 | `icon_font` + `iconFontFamily: "lucide"` |
| 边框 | `stroke`(颜色) + `strokeWidth` + `strokeAlignment: "inner"` |
| 命名 | 每个节点都有语义化 `name`（会显示在工具的图层面板里） |
| 约定 | 老师每个原型底部都有「**关键需求标注**」区块 → 本批 9 个全部沿用 |

| 属性名未越界（严格按逆向 schema） | 9/9 ✔ |
| 尺寸为整数或 `fill_container` | 9/9 ✔ |
| 字体 / 字重 / 颜色值合法 | 9/9 ✔ |
| **内容完整性（字段 + 按钮）** | **174/174 项命中 ✔** |

**修复记录**
1. 首轮 `text.width` 写出浮点数（`624.0`），与老师原型的整数约定不符 → 已在生成器层统一取整。
2. 角色矩阵页的文本节点名误用随机 id → 已改为语义化命名，并在校验器加了对应规则，锁死这类问题。
3. **布局语义错误（做 2.9 时回头发现的，属已交付产物的缺陷）**：6 个 shell 型页面（态势大盘 / 审核工作台 / 策略与规则 / 事件仿真 / 审计日志 / 系统设置）误用了 `layout="none"`（绝对定位模式），但其子节点 `sidebar` 与 `main` **都没有 x/y** → 在老师的工具里会**全部叠在 (0,0)**。
   对比老师原文件可确认：`layout:"none"` 的子节点**都带 x/y**（如 `后台菜单 x=0 y=0`、`主内容区 x=204 y=28`）；**省略 `layout` 的容器子节点才是并排**。
   已把 6 个页面改为**省略 `layout`**（横向排列），并给处置弹窗的 `mask` 补上 `x=0,y=0`、角色矩阵页改为 `vertical`。
   同时在校验器新增「**布局语义检查**」：凡 `layout="none"` 的容器，其 frame 子节点必须都带 `x`/`y`，否则报错——从机制上防止复发。
