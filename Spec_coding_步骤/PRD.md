## 电商风险控制系统
- 项目目标：实现一个面向电商业务的实时风险控制系统，覆盖羊毛党刷券、黄牛恶意囤货、虚假交易刷单、恶意退款索赔等核心业务风险场景，构建实时特征计算、规则与模型双引擎决策、实体关联图谱、案件人工复核与处置留痕的端到端闭环
- 交付形式：提供可运行前端（风控大盘、审核工作台与策略配置）、后端决策与管理服务、模拟电商风险事件流数据集、典型作弊对抗案例与完整演示链路

#### 2.3.1 开发范围
- 实时事件接入与特征计算：接入用户登录、营销领券、订单创建、在线支付、售后退款五类关键业务事件，实时提取用户行为频次、设备环境指纹、网络 IP 分布、收货地址聚集度等多维特征快照
- 多层决策引擎：支持黑白名单快速过滤、动态规则集匹配、分值累加打分机制与综合决策仲裁（放行 Pass、挑战 Challenge、人审 Review、拦截 Reject）
- 案件流转与协同处置：高危事件或待审事件自动沉淀为风控案件，提供多维画像下钻、作弊证据链呈现、关联团伙图谱分析、一键处置（拦截订单、拉黑账号、封禁设备）与操作审计
- 策略配置与名单管理：规则增删改查、阈值评分配置、规则启停用控制、多维度名单库（用户、手机号、IP、设备、地址）统一维护
- 运营监控与模拟排查：实时风控态势监控、规则命中排行、资损防护统计，提供事件在线仿真模拟测试工具

#### 2.3.2 用户角色与权限
- `风控审核员`：查看待审风控案件、核对行为证据链与关联图谱、录入人工复核结论并执行业务处置
- `风控策略师`：配置与调整风控规则集、调整规则权重与判定阈值、维护多维名单库、执行策略回测与仿真分析
- `系统管理员`：维护系统运行配置、监控事件吞吐性能与接口调用健康度、查阅操作审计流水

#### 2.3.3 页面需求
- `风控态势大盘页`：展示实时事件请求量、拦截率趋势折线图、风险等级分布环形图、规则命中排行榜与预估挽回资损卡片
- `风控审核工作台`：
  - `案件筛选与列表区`：支持按风险等级、事件场景、审核状态、触发时间筛选案件，展示待审工单列表与简要风险标签
  - `证据链与画像详情区`：展示涉事用户全貌画像、当前订单信息、实时特征快照对比及关联实体图谱（同设备/同 IP/同地址聚集账号）
  - `研判与处置协同区`：展示系统风险判定摘要与证据提示，提供处理结论选择（放行/拦截/拉黑）、处置原因备注与一键执行按钮
- `策略与规则配置页`：展示风控规则列表（支持按场景分类、启停状态切换、权重分值修改与条件表达式编辑），内嵌多维名单库管理标签页（黑/白/灰名单维护与批量导入）
- `事件仿真测试页`：提供结构化事件参数输入表单，实时触发模拟检测，单步呈现特征提取结果、规则命中链路与最终决策输出

#### 2.3.4 风控决策与流转规则
- 事件接入与特征构建规则：
  - 支持 `login`、`coupon_receive`、`order_create`、`order_pay`、`after_sale_apply` 五类事件
  - 动态计算滑动窗口统计特征（如近 1 小时同设备下单次数、近 24 小时同收货手机号退款率、同 IP 注册账号数等）
- 决策评级与仲裁规则：
  - 白名单命中直接判定为放行（Pass），黑名单命中直接判定为拦截（Reject）
  - 规则集按分值累加机制计算风险综合得分（0~100 分）：
    - 0~59 分：判定为低风险（Pass，正常放行）
    - 60~79 分：判定为中风险（Review，生成人工审核案件或触发二次验证）
    - 80~100 分：判定为高风险（Reject，直接拦截交易并自动创建风险案件）
- 案件生成与协同处置规则：
  - 判定结果为 Review 或 Reject 时，系统自动生成风控调查案件
  - 审核人员完成案件处置后，系统联动更新业务订单状态（如取消未支付订单、拒绝售后退款申请），并将处置过程记入不可篡改的审计日志

#### 2.3.5 前端模块要求
- `态势大盘模块`：负责核心指标卡片、趋势图表、规则命中排行与实时事件滚屏渲染
- `审核工作台模块`：负责案件列表分页、复合条件过滤、用户画像折叠卡片、特征表格与实体拓扑图展示
- `处置交互模块`：负责处理结论提交、关联名单添加弹窗与处置操作二次确认
- `策略配置模块`：负责规则条件树状构建器、权重分值表单、列表快速开关与名单库维护
- `仿真测试模块`：负责测试用例模板加载、动态 JSON/表单参数构建与执行链路可视化展示

#### 2.3.6 后端模块要求
- `事件网关模块`：负责接收业务端风控请求，校验事件格式并分发至决策流水线
- `特征计算引擎`：负责维护滑动时间窗口缓存，实时聚合用户历史行为特征
- `规则决策引擎`：负责执行名单匹配、条件表达式计算、分值累计与综合仲裁
- `案件流转模块`：负责风险案件创建、状态机流转（待审、审核中、已处置、已归档）与关联处置动作触发
- `画像与图谱模块`：负责按用户、设备、手机号聚合风险标签，构建同构实体关联网络
- `监控与审计模块`：负责风控决策指标统计汇总，全量记录审核操作与规则变更日志

#### 2.3.7 核心业务流程
- `实时交易风控检测流程`：
  1. 业务系统发起订单或支付等关键操作时，调用风控系统传入事件参数
  2. 风控系统执行黑白名单快速过滤，并行计算实时上下文特征快照
  3. 规则引擎依次执行策略判定，累加命中规则分值，得出最终风险等级与决策动作
  4. 系统同步返回决策结果（放行/拦截），并将全量特征快照与命中记录异步持久化
- `高危案件调查与处置流程`：
  1. 命中高危规则或达到人审阈值的事件自动推送到风控审核工作台
  2. 审核人员在工作台调取该案件，查看用户画像、行为特征快照与设备关联图谱
  3. 审核人员确认违规事实后，选择“违规拦截并拉黑用户”，录入核查依据并确认提交
  4. 系统自动执行处置动作，同步拦截关联订单并将涉事主体加入黑名单库
- `风控规则上线与调优流程`：
  1. 策略师在策略配置页创建或编辑风控规则，设定触发条件与风险分值
  2. 在仿真测试页载入典型历史作弊样本，验证规则命中效果与误伤情况
  3. 验证无误后开启规则，新规则立即对线上实时事件生效

#### 2.3.8 结果输出格式
- `事件基本信息`：事件编号、事件类型、涉事用户编号、业务单据编号与请求时间戳
- `决策结果`：风险评分（0~100）、风险等级（低/中/高）、处理建议（Pass/Review/Reject）
- `规则命中明细`：命中规则编码、规则名称、单项风险分值与触发原因描述
- `特征上下文快照`：包含行为频次、环境指纹、设备聚集度等关键特征的键值结构
- `审核留痕信息`：审核案件编号、处理人员、处理结论、处置动作明细与审核时间

#### 2.3.9 示例业务场景
- `电商大促羊毛党批量领券场景`：短时间内大量新注册账号使用相同设备指纹或同一代理 IP 聚集领取高额优惠券，系统识别设备聚集特征并直接拦截
- `高价值商品恶意退款欺诈场景`：特定用户在短时间内频繁发起高额商品“未收到货”退款申请，系统识别其收货地址存在多账号关联历史退款记录，触发人工审核案件并建议驳回退款
- 至少任选一个场景完成端到端全流程演示

#### 2.3.10 验收标准
- 能接入并正确解析五类核心电商业务事件
- 能实时计算行为频次与设备环境等风控特征，并生成特征快照
- 能根据预设规则集完成风险评分与决策仲裁，正确输出放行、人审或拦截结论
- 产生中高风险事件时能自动创建风控案件并在工作台展示
- 能在审核工作台查看用户画像、特征快照与关联证据，完成人工复核与处置闭环
- 能新增、编辑、启停用风控规则，并在名单库中维护黑白名单
- 能在仿真测试页完成单条事件的模拟检测与判定链路回溯
- 能在态势大盘查看实时拦截率、风险分布与规则命中排行
- 能完成至少一个典型作弊对抗场景的全流程演示
